# 📋 Clipboard Manager for Linux

A lightweight and fast **clipboard history manager** designed for Linux,Windows and MacOS.  
This tool keeps a history of your copied text, displays a **shortened preview** for large content, and allows you to **quickly re-paste** any previous item from the list.

## 🚀 Features

- ✅ **Real-time clipboard monitoring**
- 🧠 **Automatic text summarization** for large copied content
- 🧾 **Clipboard history list** with easy navigation
- ⚡ **Instant popup** for fast selection and pasting
- 🐧 Optimized and tested on **Linux**
- 🧰 Lightweight — minimal CPU and memory usage

## 🖼️ How It Works

1. Run the application in the background.  
2. Every time you copy something, it will be stored in the clipboard history.  
3. Press the **ctrl+alt+shift+V** (or open the popup) to view your clipboard history.  
4. Select an item → It’s copied back to the clipboard and automatically pasted.
